# 📚 Banco de Dados I

## 📌 Descrição

Este repositório contém aulas e atividades desenvolvidas durante a disciplina de Banco de Dados I. O objetivo é registrar estudos e práticas utilizando SQL Server, com foco na aprendizagem de comandos e conceitos fundamentais de banco de dados.

## 📁 Estrutura do Repositório

* 📂 aulas → exemplos e conteúdos apresentados durante as aulas  
* 📂 atividades → exercícios e práticas realizadas ao longo da disciplina  

## 🧠 Conteúdos Abordados

* Comandos gerais de SQL  
* Criação e manipulação de tabelas  
* Consultas utilizando SELECT  
* Inserção, atualização e remoção de dados  
* Filtros e ordenação de resultados  
* Relacionamentos entre tabelas  
* Conceitos básicos de banco de dados relacionais
